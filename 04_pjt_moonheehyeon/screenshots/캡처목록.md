## 확인 범위

- F402·F404의 모델과 F403·F405의 폼은 화면만으로 코드 구조까지 입증할 수 없으므로 [사용자 모델](../accounts/models.py), [사용자 폼](../accounts/forms.py), [도서 모델](../books/models.py), [도서 폼](../books/forms.py)도 함께 확인합니다.
- NF401의 URL namespace·이름 기반 연결은 [프로젝트 URL](../mypjt/urls.py), [도서 URL](../books/urls.py), [회원 URL](../accounts/urls.py)에 구현되어 있습니다.
- 17번은 원본 DB에 실제로 저장되어 있던 AI 생성 결과를 복사본에서 표시한 화면입니다. 이 캡처 작업 중에 GMS를 다시 호출하거나 생성 결과를 임의로 만들어 넣지 않았습니다.
- 캡처 환경의 외부 네트워크 제한에 대비해 실제 검색된 알라딘 표지를 서버에 저장하고 로컬 이미지 주소로 제공했습니다. `소년이 온다`와 `구의 증명`은 실제 표지가 표시된 상태로 다시 촬영했습니다. 외부 CDN이 차단된 경우에는 앱에 포함된 기본 레이아웃 스타일을 사용합니다.
- 13번의 AI 서비스 안내는 캡처용 서버에서 GMS 키를 비활성화했기 때문에 나타납니다. 도서 등록 성공 여부와 AI 생성 성공 여부는 별개이며, 기존 생성 결과는 17번에서 확인합니다.
- 테스트용 도서와 계정은 등록·수정 후 삭제·탈퇴했습니다. 사용자 원본 DB와 `.env`는 수정하지 않았습니다.
