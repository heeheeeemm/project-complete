[ Problem A1 ]
1) 단계별로 구현 과정 중 학습한 내용
json.load()를 통해 JSON 데이터를 파이썬 딕셔너리로 변환한 뒤, item 키를 순회하며 title 값을 추출해 리스트에 담는 방법을 학습했습니다.


2) 어려웠던 부분
데이터의 정확한 키 구조를 파악하지 못해 헤매거나, 경로 표기법 문제로 인한 오류가 발생할 수 있는 점이 까다로웠습니다.

3) 새로 배운 것들 및 느낀 점
작은 코드이지만 데이터를 다룰 때 예외 처리와 안전한 자원 관리가 얼마나 중요한지 몸소 느낄 수 있었습니다. 단순히 코드를 실행하는 것에 그치지 않고, 발생할 수 있는 변수를 고려하여 튼튼한 코드를 작성하는 습관의 중요성을 깨닫는 계기가 되었습니다.

[ problem_A2 ] 
1) 학습한 내용
JSON 파일에서 도서 가격 데이터를 불러와 리스트에 저장하고, sum()과 len()을 활용해 평균 가격을 계산하는 방법을 학습했습니다. 파일 처리와 데이터 분석의 기본 과정을 익혔습니다.

2) 어려웠던 부분 
JSON 데이터에서 필요한 가격 정보를 추출하고 리스트에 저장하는 과정이 어려웠습니다. 평균 계산 과정에서 리스트의 합계와 개수를 활용하는 원리를 이해하는 데 시간이 필요했습니다.

3) 새로 배운 것들 및 느낀 점
데이터를 수집한 후 원하는 값을 계산하고 분석하는 방법을 새롭게 배웠습니다. 간단한 코드로도 데이터를 의미 있는 정보로 변환할 수 있다는 점이 흥미로웠습니다.

[ problem A3 ] 
1) 단계별로 구현 과정 중 학습한 내용
pathlib과 json 라이브러리를 활용해 파일을 안전하게 열고 데이터를 딕셔너리로 변환하는 방법을 배웠습니다.
반복문과 내장 함수(sum, len)를 사용해 원하는 데이터를 추출하고 평균값을 계산하는 법을 익혔습니다.

2) 어려웠던 부분
데이터 내부의 각 항목(item)마다 리뷰 순위(customerReviewRank) 키가 항상 올바르게 존재하는지, 혹은 누락된 데이터가 있을 때 연산 과정에서 오류가 발생하지 않을지 걱정되었습니다.

3) 새로 배운 것들 및 느낀 점
단순히 데이터를 화면에 출력하는 것을 넘어, 데이터를 가공하고 평균을 도출해내는 로직을 구현하면서 데이터 처리의 재미를 느낄 수 있었습니다. 작은 기능이지만 실제 데이터 분석의 기초 단계를 직접 구현해 본 유익한 경험이었습니다.

[ problem_A4 ] 
1) 학습한 내용
json과 pathlib을 활용해 JSON 파일을 불러오고, 도서 정보를 딕셔너리 형태로 저장·출력하는 방법을 학습했습니다. 반복문과 딕셔너리를 이용해 데이터를 원하는 형태로 가공하는 과정을 익혔습니다.

2) 어려웠던 부분
JSON 데이터의 리스트와 딕셔너리 구조를 이해하고, 필요한 값을 정확히 가져오는 부분이 어려웠습니다. 특히 딕셔너리에 데이터를 저장하는 방식과 파일 경로 관리가 헷갈렸습니다.

3) 새로 배운 것들 및 느낀 점
외부 데이터를 불러와 Python으로 처리하는 방법을 새롭게 배웠고, 데이터 구조를 이해하는 것이 중요하다는 것을 느꼈습니다. 앞으로 다양한 파일 형식의 데이터를 다뤄보고 싶습니다.

[ problem A5 ]
1) 단계별로 구현 과정 중 학습한 내용
조건문과 딕셔너리를 활용해 데이터를 정가 범위에 따라 분류하고 그룹화하는 방법을 배웠습니다.
.get() 메서드를 사용하여 키가 누락되었을 때 발생할 수 있는 오류를 방지하고 안전하게 데이터를 추출하는 법을 익혔습니다.

2) 어려웠던 부분
도서의 정가 기준에 따라 데이터를 여러 그룹으로 나누어 딕셔너리에 담는 로직을 설계할 때, 조건문의 범위를 정확하게 나누는 것과 존재하지 않는 키에 접근할 때 발생할 수 있는 잠재적 오류를 예방하는 과정이 다소 까다로웠습니다.

3) 새로 배운 것들 및 느낀 점
단순히 리스트에 데이터를 모으는 것을 넘어, 딕셔너리의 구조를 활용해 데이터를 카테고리별로 분류하고 체계적으로 정리하는 방법을 익힐 수 있어 유익했습니다. 특히 예외 상황을 고려한 .get() 메서드 활용의 중요성을 깨닫는 계기가 되었습니다.
