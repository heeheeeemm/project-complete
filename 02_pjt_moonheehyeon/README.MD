### 1. 학습한 내용

이번 과제를 통해 Python에서 API를 활용하여 외부 데이터를 가져오는 방법을 학습했습니다. requests 라이브러리를 사용하여 알라딘 API에 GET 요청을 보내고, JSON 형식으로 받은 응답 데이터를 Python의 딕셔너리 형태로 변환하여 필요한 도서 정보를 가져오는 과정을 실습했습니다. 또한 .env 파일에 API 키를 저장하고 python-dotenv를 이용하여 환경 변수로 불러오는 방법을 배웠습니다. 가져온 도서 데이터를 필요한 정보만 정리하여 txt 파일로 저장하고, gTTS 라이브러리를 활용하여 도서 제목을 음성 파일로 변환하는 방법도 학습했습니다.

## 2. 어려웠던 부분

API를 처음 사용하다 보니 요청에 필요한 URL과 파라미터를 설정하는 부분이 어려웠습니다. 특히 API에서 반환되는 JSON 데이터의 구조를 확인하고, 그 안에서 도서 제목이나 가격과 같은 필요한 정보를 찾아오는 과정이 헷갈렸습니다. 또한 .env 파일에 저장한 API 키를 Python 코드에서 올바르게 불러오는 과정과 필요한 라이브러리를 설치하는 부분에서도 오류가 발생하여 해결하는 데 어려움이 있었습니다. 하지만 오류 메시지를 확인하면서 원인을 하나씩 찾아 해결하는 방법을 익힐 수 있었습니다.

### 3. 새로 배운 것들 및 느낀 점

이번 과제를 통해 단순히 Python 코드만 작성하는 것이 아니라 외부 API와 여러 라이브러리를 함께 활용하여 실제 데이터를 처리할 수 있다는 것을 배웠습니다. 특히 requests, python-dotenv, gTTS와 같은 라이브러리를 사용하면서 각각의 기능을 조합하여 하나의 프로그램을 만들 수 있다는 점이 인상적이었습니다. 처음에는 API와 JSON 데이터가 어렵게 느껴졌지만 직접 데이터를 가져오고 파일과 음성으로 변환해 보면서 이해할 수 있었습니다. 앞으로도 API를 활용하여 다양한 데이터를 가져오고 Python으로 처리하는 방법을 더 연습하고 싶습니다.
